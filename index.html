02 / CORE CAPABILITIES

Core Capabilities · 核心能力

三项核心能力及其独立 Demo 展示位。

01

主动服务

Model-Initiated Conversation · MIC

观察 → 等待 → 适时回应

无需针对当前事件的用户提问，结合视频和已有对话，决定是否开口、何时开口以及讨论什么。

02

工具调用

Stream-Aware Tool Calling · SATC

意图→工具→结果

把需求转成工具选择与参数，并结合执行结果继续提供帮助。

03

视觉交互

Interactive Visual Grounding · IVG

目标物体“你面前的这一个”

将回应关联到画面中的具体对象与证据，明确“在说谁、指哪里”。

04 / METHOD

Method · 技术框架与训练方法

长期交互记忆
